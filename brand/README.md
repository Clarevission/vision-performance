# Brand masters

Full-resolution source images. They are **not** served by the website (only `public/` is).
`npm run images` (scripts/optimize-images.js) generates the web-sized files in `public/assets/img/`
from these masters.

- `logo-dark-alt.png`: primary VPI wordmark master (used for the header/footer wordmark, favicons and share image)
- `logo-badge.png`, `logo-dark.png`, `logo-full.png`, `logo-light.png`: other logo variants (currently unused on the site)
- `favicon-master.png`: the original 2048px favicon master (superseded by the wordmark icons)
- `van-concept-master.webp`: concept livery render used for the mobile-clinic images
